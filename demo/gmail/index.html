📧Gmail メール送信スクリプト デモ

Python + Gmail API（OAuth 2.0）でCLIからメールを送信するスクリプトの動作イメージです。

⚠️
実行シミュレーション（実際のメール送信は行いません）
以下のターミナル表示は架空データによる動作再現です。Gmail APIへの接続・認証情報の読み込み・メール送信はいずれも行われていません。
token.json が有効な状態でメールを送信
send_gmail.py Python · GitHub公開中

🔧 セットアップ手順

1
Google Cloud Console でプロジェクト作成
console.cloud.google.com でプロジェクトを作成し、Gmail API を有効化します。
2
OAuth 2.0 クライアント ID を作成
「認証情報」→「OAuthクライアントID作成」→ アプリの種類：デスクトップアプリ を選択し、credentials.json をダウンロードしてスクリプトと同じディレクトリに配置します。
⚠️ credentials.json は絶対にリポジトリへコミットしないでください（.gitignore で除外済み）
3
依存パッケージをインストール
pip install -r requirements.txt
4
スクリプトを実行
python send_gmail.py
初回実行時はブラウザが起動しGoogleアカウント認証を求められます。認証後に token.json が自動生成され、次回以降は認証なしで実行できます。
